# HBat

EdgeTX 用の **バッテリー残量ウィジェット**です。残量(%)と消費容量(mAh)を `75%(1250mAh)` の形で1行に表示します。

電流センサー(Curr)を**時間で積分**して消費容量を求めるので、ELRS のテレメトリー比やパケットレートに左右されません。開始時の残量は、無負荷のパック電圧から求めます(作者の別ウィジェット VoltFuel と同じ方式)。

```
75%(1250mAh)
○○○○○○○○○○○○○○○○○○○○   ← 円を並べた残量バー(赤 / 橙 / 緑)
```

> **注意**: 電圧と電流から求める**推定値**です。実際の残量とは異なる場合があります。着陸判断の唯一の基準にしないでください。

## 特長

- 残量%と消費mAhを1行で表示(幅に収まるようフォントを自動で選択)
- Curr を時間で積分するため、テレメトリー比に依存しない
- 開始時の残量を、無負荷のパック電圧から決定(満充電でないパックでも、その時点の残量から数える)
- 電流の補正倍率(`CurrGain`)で、ESC の電流センサーの誤差を校正できる
- 円を並べた残量バー(20分割、赤 20% まで / 橙 50% まで / 緑)
- 残量%をテレメトリーセンサー `HBat` として出力可能(音声読み上げ、ロジカルスイッチ、ログ記録に使える)
- 電源が接続されていない間は `0%(0mAh)`。接続を外したあとは最後の値を保持
- 自動リセットなし(着陸時や電波途切れで勝手に戻らない)

## 動作環境

- EdgeTX 2.11 以降の、カラー液晶の送信機(作者の環境は EdgeTX 2.12)
  - オプションが9個あるため、1ウィジェット10個まで使える 2.11 以降が必要です
- テレメトリーで次の2つが取れること
  - パック電圧(単位 V)
  - 電流(単位 A)
- 作者の環境: Hobbywing Platinum 120A V4 の ESC テレメトリーを、ELRS 受信機で直接受信(テレメトリー比 1:32)

## インストール

1. このリポジトリの `WIDGETS/HBat` フォルダを、SD カードの `/WIDGETS/HBat/` にコピーします(`/WIDGETS/HBat/main.lua` になります)。
   - フォルダ名は 8 文字以内にしてください(EdgeTX の制限)。
2. 送信機を再起動します。
3. メイン画面を長押しして、ウィジェットを追加 → `HBat` を選びます。
4. ウィジェットを長押しして、設定(Settings)を開き、下の「設定項目」のとおりに設定します。

## 設定項目

| オプション | 内容 | 初期値 |
|---|---|---|
| `CurrSrc` | 電流センサー(単位 A) | 未設定 |
| `Capacity` | バッテリー容量(mAh)。0〜7000、10mA 単位に丸めます | 5000 |
| `CurrGain` | 電流の補正倍率(%)。50〜200、100 で補正なし | 100 |
| `VoltSrc` | パック電圧センサー(単位 V)。**必須**です | 未設定 |
| `Cells` | セル数。0 で電圧から自動判定します | 0 |
| `ResetSw` | スイッチまたはロジカルスイッチ。上げた瞬間に積算を0に戻し、開始電圧を取り直します | 未設定 |
| `TelemOut` | `On` で残量%をテレメトリーセンサー `HBat` として出力します | Off |
| `Color` | 文字色 | 白 |
| `BattType` | LiPo / LiPo-HV / Li-Ion / LiFePO4。セル数の判定と、電圧→%の換算に使います | LiPo |

> `VoltSrc` にはパック電圧を指定してください。受信機の BEC 電圧では動きません。`VoltSrc` が未設定だと、`Select VoltSrc` と表示されて 0% のままです。

## 表示

- 左上に `残量%(消費mAh)` を1行で表示します。
- 下に円を並べた残量バーを表示します。点灯は塗りつぶし、未点灯は輪郭のみです。円の数は、`main.lua` 冒頭の `BAR_DOTS`(初期値 20)で変えられます。
- `Color` で変えられるのは文字色だけです。バーの色(赤・橙・緑)は固定です。
- 括弧内のmAhは、補正倍率(`CurrGain`)込みの**積分した消費容量**です。開始電圧から求めたオフセットは含みません。充電器の充電量と比べる用途に使えます。
- 右上の小さな文字は、次の状態を表します。

| 表示 | 意味 |
|---|---|
| `Select VoltSrc` | `VoltSrc` が未設定 |
| `Check VoltSrc` | 電圧が、パック電圧として妥当な範囲(70V 以下)にない |
| `Acquiring...` | テレメトリーは届いているが、セル数の判定・電圧の安定待ち |

## 動作の仕様

### 電源投入から開始まで

1. 機体の電源が入っていない間は `0%(0mAh)` を表示します。
2. 電圧が届くと、セル数の判定と電圧の安定を待ちます(`Cells` を指定した場合は約2秒、自動判定の場合は約8〜9秒)。
3. 安定したら、そのときの電圧(1セルあたり)を電圧→%のテーブルで換算して、**開始時の残量**とします。
   - テーブルとセル数の判定規則は、EdgeTX の BattAnalog ウィジェットと同じです(VoltFuel と共通)。
4. 以後は、電流の積分で減っていきます。

内部では、次の式で計算しています。

```
開始オフセット(mAh) = (100 − 開始電圧から求めた%) × Capacity ÷ 100
消費(mAh)           = Σ ( Curr[A] × CurrGain[%] ÷ 100 × 経過時間[ms] ÷ 3600 )
残量(%)             = 100 − (開始オフセット + 消費) ÷ Capacity × 100
```

### 飛行中

- 電流の値を時間で積分します。テレメトリーの更新間隔には依存しません。
- テレメトリーが途切れている間(RSSI が 0)は積分を止めます。

### 機体の接続を外したあと

最後の残量%と消費mAhをそのまま表示し続けます。

### パックを交換するとき

自動ではリセットされません。次のどちらかで行ってください。

- 送信機の電源を入れ直す
- `ResetSw` を上げる(積算を0に戻し、**その時点の電圧**から開始残量を取り直します。機体が静止して、電圧が落ち着いてから操作してください)

### すでに負荷がかかっている状態で始まった場合

飛行中に送信機の電源が入った場合など、起動時に電流が 1A を超えていると、電圧が使えないため、開始オフセットなしで始めます(満充電とみなします)。

## テレメトリー出力

`TelemOut` を `On` にすると、残量%がテレメトリーセンサー `HBat`(単位 %)として出力されます。

- テレメトリー画面で **Discover new sensors** を実行すると、センサー一覧に追加されます。
- 音声読み上げ、ロジカルスイッチ、SD ログ記録に使えます。
- 開始電圧が確定するまでは出力されません。
- センサーIDは `0x5C00` です。他のセンサーと衝突する場合は、`main.lua` 冒頭の `TELEM_ID` を変えてください。
- Lua から付けられるセンサー名は短いため、名前は `HBat(%)` ではなく `HBat` です。

## 校正

開始電圧、電流、容量の3つが、残量の精度に効きます。手順は [docs/calibration.md](docs/calibration.md) にまとめています。

- 電圧: 信頼できる電圧計と比べて、センサーの Offset / Ratio で合わせる
- 電流: 充電器の充電量と比べて、`CurrGain` を合わせる
- 容量: `Capacity` を、パックの実容量に近い値にする

## なぜ自前で積分するのか

EdgeTX の計算センサー(Calculated → Consumption)でも、電流から消費容量を出せます。ただ、作者の環境(Hobbywing ESC + ELRS)では、テレメトリー比を 1:128 から 1:32 に変えただけで、積算された容量が大きく変わりました。原因の詳細は確認できていません。

そこで HBat では、送信機の時計で経過時間を測って、電流を積分する方式にしました。

## 制限

- 電圧と電流から求めた**推定**です。実際の残量に対する精度は、作者の環境でもまだ十分には検証できていません。
- 電圧→%のテーブルは、LiPo(4.2V/セル)などの一般的な特性です。劣化したパック、低温のパック、他のケミストリーでは検証していません。
- 開始電圧は、**無負荷で落ち着いた電圧**で決めます。接続直後や充電直後は、電圧が高めに出ることがあります。
- 自動セル判定は、深く放電したパックを、セル数が1つ少ないと誤判定することがあります。その場合は `Cells` を指定してください。
- 積算値は、送信機の電源を切ると失われます。
- ESC の Curr の精度は、機種によって異なります。`CurrGain` で合わせてください。
- Lua の `setTelemetryValue` を使うテレメトリー出力(`TelemOut`)は、EdgeTX のバージョンによって動作が異なる可能性があります。
